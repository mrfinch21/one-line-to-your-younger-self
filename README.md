## The line

> Kid, the airdrop you're refreshing at 3 a.m. isn't worth the sleep it costs — go to bed, the chain will still be there tomorrow.

One line, in English, written to my younger self: the late-night refresh habit, the sleep it costs, and the one thing the older self knows now — the chain isn't going anywhere, so neither should the night.

## Run

```sh
node main.ts
```

`main.ts` (Node 22, no dependencies, no network, deterministic) writes the line to `/output/entry.txt` — 128 characters, inside the 1–200 character gate.
